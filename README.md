# BIS — Building Intelligence System

ИИ-платформа для строительных компаний: агенты, оркестратор, RAG по нормативам и документам
организации, генерация исполнительной документации, CAD-схемы, голосовое управление.

- [План, архитектура, трудозатраты, ресурсы](docs/PLAN.md)
- [Запуск, настройка гибридного ИИ, плагины](docs/DEVELOPMENT.md)

## Что уже работает (фаза 1)

- **База знаний**: загрузка PDF, DOCX, XLSX, TXT и писем EML. Нормативы разбиваются по пунктам,
  поиск гибридный (векторный, полнотекстовый, точная ссылка «СП … п. …»), ответы с цитатами
  и статусом редакции.
- **Агенты**: Нормоконтроль, Секретарь (письма), ПТО (АОСР), Помощник. Супервизор выбирает агента
  сам. Все действия агентов пишутся в журнал аудита.
- **LLM-шлюз (гибрид для РФ)**: локальные модели (vLLM, Ollama), GigaChat, YandexGPT, Claude.
  Маршрут выбирается по уровню данных; персональные данные маскируются перед отправкой в облако;
  есть офлайн-режим без модели.
- **Документы**: АОСР по Приказу Минстроя № 344/пр с автоматической проверкой полноты,
  деловое письмо по ГОСТ Р 7.0.97. Можно подключить шаблоны DOCX организации. Нумерация автоматическая.
  Документ проходит путь «черновик → утверждение/отклонение».
- **Реестры**: объекты, контрагенты, договоры, ответственные, назначения по приказам (с номером НРС),
  обязательства по договорам.
- **Адаптация под компанию**: правила и память организации; замечания при отклонении документа
  становятся правилами для агента.
- **Платформа**: мультиарендность, роли и права, SDK плагинов (инструменты в формате MCP),
  Docker Compose, CI.

```bash
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml exec api bis seed-demo   # вход: admin@demo.bis / demo12345
```
