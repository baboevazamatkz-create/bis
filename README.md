```

Искусственный интеллект, встроенный в производство строительной компании. Не CRM и не оболочка
делопроизводства: люди на объекте присылают то, что у них и так есть (фото, голосовые, накладные, сертификаты,
протоколы, съёмку, письма), а несколько ИИ-специалистов превращают это в данные и документы. Человеку остаются
решения: принять, исправить, отклонить. Исправления становятся примерами, отказы — правилами.

## Как это работает

```
Telegram · почта · загрузка · API  →  восприятие (зрение, слух, чтение)  →  диспетчер  →  специалист
   →  политика самостоятельности (сделать сам / спросить)  →  контролёр сверяет  →  «Лента ИИ»: решения людей
```

| ИИ-специалист | В чём силён |
|---|---|
| Диспетчер | Понимает, что пришло с объекта, и передаёт нужному специалисту |
| Зрение | Фото с площадки: вид и стадия работ, дефекты, нарушения охраны труда; фото документов |
| Чтец документов | УПД, ТТН, сертификаты, паспорта качества, протоколы испытаний → данные |
| Слух | Голосовые прорабов → объёмы работ, расход материалов, проблемы |
| Инженер ПТО | Сам собирает АОСР по сданной захватке: объёмы, материалы с сертификатами, схемы, РД, нормы |
| Юрист | Договоры: обязательства, сроки, неустойки, риски — на контроль с напоминаниями |
| Экономист | Сверка проекта со сметой, КС-2/КС-3, М-29 |
| Геодезист | Исполнительные схемы DXF по съёмке, допуски |
| Секретарь | Письма: регистрация, суть, срок ответа, поручения по ролям |
| Контролёр | Ловит противоречия: цена выше обычной, расход больше прихода, перерасход к норме, объём сверх сметы, истёкшие сертификаты, несоответствие в протоколе |
| Аналитик | План-факт и прогноз сроков по фактическому темпу |

**«Синапс» — мозг объекта.** Для каждого документа — карточка (вид, №, дата, стороны, РД: шифр, листы, изменение;
конструкции, материалы и марки, оси, отметки, нормы, суть), связи с другими документами (АОСР → документы о
качестве, протоколы, схемы; письмо → ответ, договор, акты; документ, загруженный позже, находит, кто на него ссылался),
постраничные ссылки и описание листов схем и чертежей моделью зрения. Цепочки переписки: какие запросы заказчика
без ответа, какой срок прошёл и какие документы из наших писем в архиве не найдены. На «Синапсе» держатся ответы ассистента и бота.

**Взято у лучших аналогов** (Procore, Autodesk, Trunk Tools, Raken, Oracle, Field Materials, сервисы ИД):
вопросы прорабов в Telegram текстом и голосом — ответ со ссылками и файлами документов; сводка дня руководителю и
напоминание прорабам без отчёта; рейтинг рисков объектов с причинами; проверка ИД по архиву — каких сертификатов,
протоколов и схем, на которые ссылаются АОСР, нет; ход работы ИИ в чате потоком; ответы на языке рабочего.

Каждый специалист работает на своей модели (локальной или облачной российской); без модели — на правилах
и алгоритмах. Что ИИ делает сам, а что предлагает, настраивает организация; система сама подсказывает,
где ИИ уже заслужил самостоятельность.

**Платформа**: гибридный LLM-шлюз для РФ (локальные модели, GigaChat, YandexGPT, Claude; маршрут по уровню
данных, маскирование ПДн, модели зрения), RAG по нормативам с цитатами пунктов, Telegram-бот и почта IMAP как
каналы с площадки, ИД по Приказу № 344/пр (АОСР, АООК, реестр ИД, журнал работ), КС-2/КС-3, М-29, схемы для
AutoCAD/nanoCAD, ассистент для вопросов, уведомления, аудит, мультиарендность, SDK плагинов (MCP), Docker Compose.

docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml exec api bis seed-demo   # вход: admin@demo.bis / demo12345
```
