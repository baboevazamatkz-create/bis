# BIS — Building Intelligence System

BIS помогает инженеру ПТО подготовить исполнительную документацию по данным объекта.
Рабочее место объединяет поиск по проектным и нормативным источникам, черновики АОСР и АООК,
исполнительные схемы и проверку комплектности. Инженер проверяет факты, основания и результат
перед утверждением.

## Локальный пилот Windows

Установка создаёт отдельный BIS-Pilot на `http://localhost:8081`. Процедуры первого запуска,
подключения источников и обновления описаны в [инструкции Windows](docs/PILOT_WINDOWS.md).

Первичная установка из закреплённого пакета:

```powershell
irm https://raw.githubusercontent.com/baboevazamatkz-create/bis/codex/pilot-readiness/deploy/install-pilot.ps1 | iex
```

Обновление уже установленного пилота из рабочей ветки. Перед обновлением закройте приложение:

```powershell
irm https://raw.githubusercontent.com/baboevazamatkz-create/bis/codex/pilot-readiness/deploy/update-pilot-windows.ps1 | iex
```

Автоматический вход предназначен для локальной работы. Состояние браузерного входа для
сетевого сценария описано в [текущем состоянии проекта](docs/CURRENT_STATE.md).
