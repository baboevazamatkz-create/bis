# BIS — Building Intelligence System

ИИ-платформа для строительных компаний: агенты, оркестратор, RAG по нормативам и документам
организации, генерация исполнительной документации, CAD-схемы, голосовое управление.

- [План, архитектура, трудозатраты, ресурсы](docs/PLAN.md)
- [Запуск, настройка гибридного ИИ, плагины](docs/DEVELOPMENT.md)

## Что уже работает

**Агенты** (главный агент выбирает исполнителя; «Помощник» раскладывает составные задачи по агентам):

| Агент | Что делает |
|---|---|
| Нормоконтроль | Ответы по СП/ГОСТ с цитатами пунктов, самопроверка ответа по источникам |
| Секретарь | Разбор входящих (почта IMAP, загрузка): регистрация, суть, срок ответа, поручения по ролям; письма по ГОСТ Р 7.0.97 |
| ПТО / ИД | АОСР по Приказу № 344/пр с проверкой полноты; представители по приказам с номерами НРС |
| Договорной | Анализ договора: обязательства сторон, сроки, неустойки, риски; расчёт пеней; претензии |
| Контроль исполнения | Поручения, просрочки, ответственные; фоновый контроль сроков с эскалацией |
| Контроль работ | Объёмы от прорабов, план-факт по ГПР, прогноз окончания, уведомления об отставании |
| Материалы | Приход, расход, остатки, М-29 (нормы против факта), акты списания |
| Закрытие работ | Проверка закрытия (АОСР на скрытые работы, подтверждение ПТО, превышение сметы), КС-2 и КС-3 |
| Исполнительные схемы | DXF для AutoCAD/nanoCAD по съёмке: отклонения, отметки, допуски, штамп (DWG через ODA) |
| Анализ ПД | Комплектность разделов ПД и РД, спецификации, сверка со сметой, ведомость замечаний |

**Платформа**: гибридный LLM-шлюз для РФ (локальные модели, GigaChat, YandexGPT, Claude; маршрут по уровню
данных, маскирование ПДн, офлайн-режим), RAG с поиском по пунктам нормативов и строительным тезаурусом,
голосовые команды (распознавание речи в закрытом контуре), уведомления (интерфейс, Telegram), память и правила
организации, обучение на замечаниях, оценка качества (`bis eval`), мультиарендность, роли, аудит действий агентов,
SDK плагинов (инструменты в формате MCP), Docker Compose, CI.

```bash
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml exec api bis seed-demo   # вход: admin@demo.bis / demo12345
```
