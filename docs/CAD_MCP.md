# AutoCAD и nanoCAD: ИИ рисует в чертеже (MCP)

BIS умеет управлять AutoCAD и nanoCAD на компьютере с Windows через их COM API. Это доступно двумя путями:

1. **Из BIS** — кнопка «Открыть в AutoCAD/nanoCAD» у исполнительной схемы (BIS установлен на том же компьютере).
2. **Из ИИ-клиента** (Claude Desktop, Claude Code) — MCP-сервер `bis-cad`: ИИ рисует по вашей просьбе
   («нарисуй сетку осей 1–5 через 6 м и А–Г через 6 м, контур плиты и размеры», «построй исполнительную схему
   колонн по этим замерам»).

Если CAD не запущен, команды пишутся в DXF-файл, который затем открывается в AutoCAD или nanoCAD.

## Подключение в Claude Desktop

Установщик BIS для Windows уже ставит нужные пакеты. В Claude Desktop включите режим разработчика
(☰ → Help → Troubleshooting → Enable Developer Mode), затем Настройки → Developer → **Edit Config** — откроется
файл, который Claude читает на самом деле (у версии из Microsoft Store он в другой папке), — и добавьте:

```json
{
  "mcpServers": {
    "bis-cad": {
      "command": "C:\\BIS\\venv\\Scripts\\bis.exe",
      "args": ["cad-mcp"]
    }
  }
}
```

Перезапустите Claude Desktop. Запустите AutoCAD или nanoCAD, откройте или создайте чертёж — и попросите ИИ нарисовать.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `cad_status`, `cad_connect` | Что подключено: AutoCAD, nanoCAD или DXF-файл; переключение |
| `cad_axes` | Сетка разбивочных осей с марками и размерами |
| `cad_line`, `cad_polyline`, `cad_circle` | Геометрия (мм) |
| `cad_text`, `cad_dimension` | Надписи и параллельные размеры |
| `cad_executive_scheme` | Целая исполнительная схема BIS: оси, контур, проект/факт, отклонения, допуски, таблица, штамп |
| `cad_save` | Сохранить в DWG/DXF |

Единицы — миллиметры (1 мм чертежа = 1 мм натуры).

## Исполнительная схема без геодезиста

В BIS «Исполнительные схемы» → «По проекту и замерам»: оси и отметка по проекту, допуски — из нормативов (ИИ находит
пункт СП), фактические отклонения — из замеров рулеткой/нивелиром текстом или голосом
(«1/А: X +8, Y −3, высота −5»). Без замеров получается схема по проекту с графами для факта.
Фото и видео дают визуальный контроль (в примечании), но не миллиметры отклонений.
