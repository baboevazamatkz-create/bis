# Рабочее место ПТО

В локальном пилоте вход автоматический. В меню шесть разделов:

| Раздел | Действия |
|---|---|
| Помощник | Текстовые и голосовые вопросы, поручения, ссылки на основания |
| Исполнительная документация | Реестр, состояние документов, проверка комплектности, поручение подготовки |
| Исполнительные схемы | Существующие схемы, отсутствующие приложения по актам, поручение подготовки |
| Проект | Рабочая документация, поиск по имени и прочитанному содержимому, вопросы по выбранному файлу |
| Договоры | Генподряд, субподряд, вопросы по конкретному договору |
| Базы данных | Знания, проект, организации: подключение папок, перечитывание, очистка |

Ручные формы актов и геометрии исключены из рабочего интерфейса. Поручение передаётся
помощнику вместе с выбранным документом; его не требуется заново искать по номеру.
Поиск в списках работает без языковой модели. Выбранный объект ограничивает проектные документы.

## Подключение и качество источников

В «Базы данных» выберите уровень и подключите папку на компьютере, где запущен BIS.
Нормативы и пустые формы относятся к знаниям; заполненные акты, РД и договоры — к проекту.
Переключатель «Использовать только мои базы» включает строгий режим источников.

«Обновить базу» принудительно перечитывает и неизменённые файлы. Результаты появляются
по мере чтения. В раскрывающемся списке видны ошибки и неполное чтение. Старые загрузки
перечитываются отдельно из сохранённых оригиналов. При ошибке повторного чтения их прежний
индекс сохраняется, а ошибка отображается пользователю.

«Очистить базу» после подтверждения удаляет записи и индекс выбранного подключения,
отключает синхронизацию. Исходная папка на диске сохраняется; для возврата нажмите
«Обновить базу». Очистка старых загрузок сохраняет созданные в BIS документы и другие проекты.
Это очистка записей источников, а не освобождение всех копий файлов на диске.

В «ИИ и качество чтения» доступны локальная настройка ключа и Folder ID, включение OCR/голоса,
необязательное подключение модели зрения и проверка моделей. Настроенный провайдер ещё
не означает успешный доступ: нужны правильный каталог, права и биллинг.
Ключ хранится локально, не возвращается через API. Облачный провайдер получает отправленные
ему фрагменты и изображения; нормативные основания берутся из подключённых источников.

## Что исправлено в чтении

- Заполненный АОСР в проектной папке больше не считается автоматически пустым шаблоном.
- DOCX: колонтитулы, вложенные таблицы, примечания; XLSX: пустые столбцы и явные предупреждения
  о формулах без сохранённых результатов. Значения формул не выдумываются.
- PDF: резервный извлекатель при повреждённом текстовом слое; OCR сканов и все страницы TIFF.
- Отказ сервиса векторизации сохраняет текстовый индекс. Ошибки чтения доступны в интерфейсе.
- Вопрос по выбранному договору сохраняет привязку к нему и не подменяется поиском общих сроков работ.

Контрольный комплект проверяет эти случаи, но не заменяет проверку реального архива.
Сложные чертежи, сканы и связи проекта требуют сверки с эталонными листами. Исполнительные
замеры, даты и состав участников нельзя получать из предположений модели.
