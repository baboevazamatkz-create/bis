## Открытые ограничения

- Оболочка пилота вызывает `/api/auth/me` и при отсутствии пользователя
  показывает ошибку подключения. Docker-сценарий с браузерной формой входа
  не следует считать готовым на рабочей ветке. Исправление локального входа
  рассматривается отдельно в [PR №4](https://github.com/baboevazamatkz-create/bis/pull/4).
- На момент сверки рабочая ветка не была защищена, а ветка по умолчанию оставалась
  `claude/construction-ai-automation-system-lya9lz`. Старые опубликованные URL и
  Linux-установщик требуют её сохранения.
- Проверка упаковщика применяется к [собранному пакету](../deploy/package-pilot.py).
  Автоматические архивы исходников GitHub, которые скачивает пилот, создаются
  независимо от упаковщика. Для обновлений из рабочей ветки важны пройденный CI
  и защита ветки.
- Продуктовая готовность требует воспроизводимого прогона на согласованном
  архиве, включая роли и границы доступа. Дальнейшие задачи фиксируются в
  [backlog](TASKS.md).
