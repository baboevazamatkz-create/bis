# Генеральный план развития BIS

Владелец проекта утвердил генеральный план. Цель BIS — единая интеллектуальная система для строительной организации, которая понимает информацию и выполняет рабочие задачи под контролем человека.

## Этапы

| Этап | Результат |
| --- | --- |
| 1. Надёжная техническая основа | Подготовительная часть завершена. |
| 2. Понимание строительной документации | Текущий этап. Первая задача P1 проверяет, что BIS находит документы и фрагменты выбранного объекта и показывает неполноту чтения. |
| 3. Законченный процесс ПТО на примере АОСР | Инженер получает проверяемый и скачиваемый черновик акта освидетельствования скрытых работ (АОСР) с комплектом оснований. |
| 4. Самостоятельное выполнение многошаговых задач | BIS выполняет последовательность рабочих шагов и запрашивает у человека подтверждение важных действий. |
| 5. Расширение платформы | BIS охватывает строительные процессы, договоры, объёмы, управление и интеграции. |
| 6. Подготовка к внедрению | BIS готовится к внедрению в строительных организациях. |

Главные показатели развития — самостоятельность, надёжность и реальная экономия времени.

## Работа команды

Три постоянные роли — координатор, разработчик и независимый ревьюер. Новые задачи должны соответствовать утверждённому плану. Текущие задачи и критерии приёмки ведутся в [очереди задач](TASKS.md). Изменение стратегического направления требует согласования с владельцем проекта.
