# Переключение BIS на Anthropic

При проверке маршрутов обнаружены и исправлены связанные ошибки:

- Проверка моделей вызывала также сохранённые, но не используемые провайдеры.
  Теперь проверяются только провайдеры, указанные в текущих маршрутах.
- При выборе Claude в конфигурацию переносились старые модели зрения Яндекса.
  Для Claude остаются Claude и локальный офлайн-ответ. OCR и vision направляются Claude.
- Поиск сохранял отдельный Yandex Embedder. При переключении с него на Anthropic
  включается локальный поиск, очищаются кэши эмбеддингов и векторов. Прежние документы сохраняются.
  Anthropic не используется как сервис эмбеддингов.
- Блокировка vision после ошибки прежнего подключения переживала смену модели.
  Сохранение подключения сбрасывает это состояние.
- Форма загружала название провайдера без соответствующей модели/адреса API.
  Теперь восстанавливаются эти значения, а фоновое обновление не сбивает редактирование.
- В статусе OCR независимо от провайдера показывался ключ Яндекса.
  Теперь отображается используемый сервис распознавания.
- Ключ `sk-ant-…` распознаётся в интерфейсе. Старая форма `/ai-setup` переводит его в настройку
  Anthropic; явный неверный выбор провайдера в новом API получает понятную ошибку до записи.
- Убран скрытый повтор сетевых запросов SDK Anthropic; для новых подключений тайм-аут 60 секунд.
  Ошибки не должны удерживать вызов несколько минут. Ключ маскируется в сообщениях API.
- OCR кодирует и освобождает PDF-страницы последовательно, не хранит все растровые страницы в памяти.
  Пустой, отклонённый или обрезанный ответ OCR считается ошибкой, а не полным текстом страницы.

Голосовое распознавание имеет отдельный STT-маршрут. Установка ключа Claude сама по себе
не подключает транскрибацию речи. Реальные права и баланс аккаунта проверяются кнопками
«Проверить ИИ» и «Проверить OCR» после ввода ключа на компьютере пользователя.

Проверка исправлений: 387 серверных тестов прошли; сборка интерфейса и Ruff прошли.
Браузерный сценарий `frontend/e2e/provider_switch.py` проверяет загрузку прежних настроек Яндекса,
распознавание ключа Claude, сохранение выбора при фоновом опросе и проверку Claude после сохранения.
Использованы синтетические ключи и управляемые ответы API. Эти проверки не подтверждают
баланс, сетевую доступность и права реального аккаунта Anthropic пользователя.
